# QuickBite React Frontend

This version is connected to the backend/API Gateway and does not use mock data.

## Run

```bash
npm install
npm run dev
```

## API base URL

Default API URL is `http://localhost:5000`.
To change it, create a `.env` file:

```env
VITE_API_BASE_URL=http://localhost:5000
```

Make sure your API Gateway/backend is running before using login, register, restaurants, menu, orders, notifications, admin, restaurant, and agent pages.
